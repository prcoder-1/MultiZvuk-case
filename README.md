# MultiZvuk Case

## Корпус для БК Мультизвук

![MultiZvuk case](MultiZvuk%20case.jpg)
![MultiZvuk case 2](MultiZvuk%20case%202.jpg)

Корпус состоит из двух частей: основного корпуса и расширителя с проходным разъёмом МПИ.
Надписи на корпусе выполнены шрифтом знакогенератора БК-0010.

Для более гармоничного сочетания с БК рекомендуется при печати использовать текстурированный столик.

Для сборки корпуса понадобятся:
- Четыре винта **M3** с потайной головкой (нижняя крышка)
- Два длинных винта **M3** с потайной головкой (расширитель, стягивают колпак, ушки разъёма и основание)

STL-модели корпуса:
- ***[MultiZvuk-Top.stl](MultiZvuk-Top.stl)*** - 3D-модель верхней части корпуса
- ***[MultiZvuk-Bottom.stl](MultiZvuk-Bottom.stl)*** - 3D-модель нижней крышки
- ***[MultiZvuk-Ext-Top.stl](MultiZvuk-Ext-Top.stl)*** - 3D-модель колпака расширителя
- ***[MultiZvuk-Ext-Bottom.stl](MultiZvuk-Ext-Bottom.stl)*** - 3D-модель основания расширителя
